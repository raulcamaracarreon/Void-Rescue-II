# Void Rescue II — v1.0.0

**Versión estable oficial · 11 de octubre de 2026**

¡Void Rescue II sale de desarrollo activo! Es un arcade espacial gratuito y de código abierto, listo para jugar desde un navegador moderno.

**▶ Jugar en línea:** https://raulcamaracarreon.github.io/Void-Rescue-II/

## Características principales

- **Clásico y Dinámico por zonas:** dos sistemas de apariciones de enemigos, seleccionables independientemente.
- **Rescatista y Defensivo:** dos misiones con objetivos propios, combinables con los dos sistemas.
- **Haz de extracción sostenido**: elevar colonos gradualmente y llevar **hasta ocho a bordo** para entregarlos juntos.
- **13 estilos de paisaje** con paralaje procedural y gradiente de colores, incluida la terna Ocaso Marciano, Nublado Polar y Planeta extraño.
- Editor automático/avanzado y **biblioteca de hasta 100 paisajes personales**.
- Rotación **secuencial o aleatoria sin repetición** de paisajes predefinidos y personales entre oleadas.
- HUD monocromático adaptable, gamepad, seis dificultades, radar, puntuación y récords separados por modalidad.
- Publicación web con **WebGPU** y **WebGL2** de respaldo.

## Descarga

**Archivo `void-rescue-ii-v1.0.0-web.zip`**: incluye la compilación estática del sitio, `LICENSE`, `THIRD_PARTY_NOTICES.md` y la guía de alojamiento. **No es un instalador ni un juego nativo de Windows.** Para ejecutarlo localmente se necesita servir los archivos mediante HTTP (por ejemplo `python -m http.server` desde la carpeta descomprimida); abrir `index.html` como `file://` puede no funcionar.

Alternativamente, **juega directamente en GitHub Pages**, sin descargar nada, o compila el código fuente siguiendo el README.
