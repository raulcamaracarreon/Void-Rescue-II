# Void Rescue II

Continuación independiente de [Void Rescue I](https://github.com/raulcamaracarreon/Void-Rescue-I), con dos objetivos principales:

1. Paisajes procedurales con paralaje (montañas y edificios), paletas predeterminadas, editor de personalización y un nuevo ambiente por oleada.
2. Sistema de aparición dinámica de enemigos por zona y tiempo. En **Rescatista**, completar la evacuación de los colonos recuperables; en **Defensivo**, resistir durante el tiempo objetivo mientras sobrevive una cantidad mínima de colonos.

**Estado:** repositorio inicial; migración del código original en preparación. Void Rescue I permanece sin modificaciones.

Referencia adicional: [Landscape Generator — Parallax](https://github.com/raulcamaracarreon/Landscape-Generator-Parallax).
